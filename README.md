# AI Recipe Generator

Сайт, который придумывает рецепт из продуктов, которые есть дома. Пользователь вводит продукты через запятую, а ИИ (Claude, Anthropic API) генерирует название блюда, описание, ингредиенты, пошаговое приготовление и время.

## Технологии

- **Фронтенд:** React + Vite + TypeScript + CSS
- **Бэкенд:** минимальный сервер на Express (`server/index.ts`): он хранит секретный ключ и обращается к ИИ через официальный SDK `@anthropic-ai/sdk`
- Ответ ИИ возвращается в строгой структуре (JSON-схема на Zod, `shared/recipe.ts`), поэтому карточка рецепта всегда заполнена корректно

Секретный API-ключ хранится только на сервере (в `.env`) и никогда не попадает в браузер.

## Запуск

```bash
npm install
cp .env.example .env   # впишите свой ANTHROPIC_API_KEY
npm run dev            # сервер API на :3001 + Vite на :5173
```

Откройте http://localhost:5173.

### Продакшен

```bash
npm run build
npm start              # Express отдаёт и API, и собранный фронтенд на :3001
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `ANTHROPIC_API_KEY` | Секретный ключ Anthropic API (обязательно) |
| `ANTHROPIC_MODEL` | Модель, по умолчанию `claude-opus-5-5` |
| `PORT` | Порт сервера, по умолчанию `3001` |

## Обработка ошибок

- Пустое поле: сообщение показывается сразу, без запроса к серверу (дополнительно проверяется и на сервере)
- Нет ключа, неверный ключ, превышен лимит запросов, нет связи с ИИ: понятное сообщение на русском
- Пока ИИ генерирует ответ, показывается индикатор загрузки, а поле и кнопка заблокированы
